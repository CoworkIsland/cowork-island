# Cowork Island

Keep track of supported AI sessions on your Mac: what is working, what **Needs you**, and what you have already reviewed. Cowork Island brings them into a notch panel so you can find the session that needs your attention.

This is the community home for questions, bug reports and feature requests. It contains community documentation, not application code.

Cowork Island is not affiliated with Anthropic.

## Who it is for

If you work with several AI sessions across terminals and compatible desktop apps, you can use the panel to check their states, organize the list and return to a session. You do not need to be a developer to use it.

Available actions depend on the tool and its integration.

## Supported tools

Cowork Island installs hook integrations for **13 tools**:

Claude Code · Codex · Gemini CLI · Cursor · TraeCli · Qoder · Copilot · Factory · CodeBuddy · Kimi Code CLI · OpenCode · Cline · Pi / Oh My Pi

Claude and Cursor desktop sessions are also supported. Approving and answering from the panel depend on the integration; the list above does not guarantee every action for every tool.

**Codex CLI** answers questions through its shared server connection. The Codex desktop app shows questions but does not answer them from the panel. Regular ChatGPT chats are not included in Codex support.

For a question about your setup, include both the agent and the terminal or desktop app you use in [Discussions](https://github.com/coworkisland/cowork-island/discussions).

## Free, Pro and trial

- **Free is permanent:** one visible session card and a counter for the remaining sessions. You can return to that session unless its state is **Needs you**; that particular jump requires Pro.
- **Pro:** all session cards and the jump from Needs you. One-time purchase: **€9.99 for one Mac, €14.99 for two Macs, or €19.99 for three Macs**.
- **7-day trial, no card required:** Pro and mascot-pack access during the trial.
- **Optional mascot packs:** Desk and Abyss cost **€1.99 each**, or **€2.99 together**.

Check the website for the offer available when you buy.

## Report a bug or suggest a change

Use the [Bug report form](https://github.com/coworkisland/cowork-island/issues/new?template=bug_report.yml). Include the app version and build, what happened, what you expected, steps to reproduce, the agent and terminal, and your macOS version. When opening it from the app, check the version field and fill it in if it is empty.

**Send the ZIP from Export Diagnostics by email to support@coworkisland.com. Never attach it to a public issue.** Include the issue number if you have one.

Use the [Feature request form](https://github.com/coworkisland/cowork-island/issues/new?template=feature_request.yml) for a proposed change. [Discussions](https://github.com/coworkisland/cowork-island/discussions) is the place for questions, ideas and sharing how you use Cowork Island.
