# Security

Report suspected vulnerabilities in Cowork Island, its licensing service or its website by email to **support@coworkisland.com**, with `security` in the subject line.

Do not report vulnerabilities in a public issue, Discussion or pull request.

Include the affected version, what you observed, the potential impact and any steps needed to reproduce the problem. Keep passwords, access tokens and other people's private data out of the report.

If you need to share the ZIP from Export Diagnostics, send it to **support@coworkisland.com**, never as an attachment to a public issue.

For a vulnerability in a third-party agent, terminal or service, use that project's security contact.
